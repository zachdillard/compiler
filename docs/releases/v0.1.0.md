## What is included

The compiler completes chapter one of Nora Sandler's *Writing a C Compiler*:
one `int` function with `void` parameters returning an integer constant, such as
`int main(void) { return 2; }`. It emits macOS x86-64 assembly or an executable.
`--lex`, `--parse`, and `--codegen` validate intermediate stages; `-S` emits
assembly without linking. Stage flags are mutually exclusive. `--help` describes
the command line, and `--version` prints `Compiler 0.1.0` without GCC.

The compiler executable runs natively on Apple Silicon and includes its .NET
runtime. Binary users need no .NET installation, Git checkout, DLLs, runtime
configuration files, or symbols. See the [binary installation guide](../../README.md#binary-installation)
for checksums, extraction, per-item approval, optional installation, and compiling
and running an example that exits with status `2`.

## Prerequisites and support

- Apple Silicon Mac. The intended minimum is macOS 14.0 (Sonoma). Runtime
  checks on macOS 14 and 15 and a final browser-download walkthrough must pass
  before publication; Mach-O deployment metadata alone is insufficient.
- Apple's Command Line Tools with `gcc` on `PATH` remain required for
  preprocessing, assembly, and linking. Full Xcode is a release-build prerequisite,
  not a binary-user requirement.
- Rosetta 2 is required on Apple Silicon to execute the compiler's generated
  x86-64 programs. The ARM64 compiler itself runs without Rosetta.
- Contributors building from source need the SDK pinned in `global.json`:
  .NET 11 RC1 `11.0.100-rc.1.26425.128`. This requirement does not apply to
  binary users.

## Signing and limitations

This is an **unsigned, non-notarized learning release**. The ARM64 executable
retains the linker's ad hoc signature, which supplies no Developer ID identity.
Developer ID signing and notarization are deferred. Browser downloads may be
blocked by Gatekeeper; use [Apple's per-item approval](https://support.apple.com/en-us/102445)
only for the verified, trusted download, as detailed in the installation guide.
The separate-machine final download and approval procedure remains a publication
gate in task 08.

Later chapters and extra credit are not implemented. Integer constants must fit
in a signed 32-bit integer, and sources must have a `.c` extension. Generated
programs are macOS x86-64; this release offers neither ARM64 code generation nor
an Intel/universal compiler download. This is a learning project using an RC
toolchain, with no compatibility claim beyond verified release environments.
Packaging does not claim bit-for-bit reproducibility.

The included notices cover the redistributed .NET runtime and System.CommandLine;
the compiler's own MIT license does not replace those notices. Chapter-based
versioning is unchanged: `v0.N.0` completes chapter N; `v0.N.P` fixes that chapter.
